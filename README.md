# BRZ Telemetry System

A modular CAN-based telemetry system for a 2014 Subaru BRZ.

## Planned Features

- Gauge-hood progressive F1-style RPM shift light
- Separate estimated-range and average-MPG display
- Passive decoding of broadcast vehicle CAN data
- OBD-II pass-through for continued diagnostic access
- Expandable architecture for future vehicle-data projects

## Current Status

Planning the system architecture and acquiring CAN-interface hardware.
